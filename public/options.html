Frequently Asked Questions

Common answers and troubleshooting tips for extension operations.

Why should I configure a GitHub Personal Access Token?

Unauthenticated requests to the GitHub REST API are limited to 60 queries per hour per IP. Providing a PAT raises this limit to 5,000 queries per hour and enables searching private repositories you own or collaborate on.

How is data communicated with the background worker?

This option view does not read or mutate chrome.storage directly. All actions send asynchronous message payloads (GET_SETTINGS, SAVE_SETTINGS, CLEAR_CACHE) over the runtime message bus to the service worker (background/index.ts).

How does theme sync work between Popup and Options?

When you save a theme preference ('dark', 'light', or 'system'), the setting is persisted via background service worker. The HTML document root (<html data-theme="...">) immediately reflects the updated theme token across all open extension views.

Where can I report a bug or suggest a feature?

You can open an issue or feature proposal directly on the GitHub Repository Issues page.
